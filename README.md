# Machine Learning

> A collection of machine-learning notebooks and experiments by Siddhesh Shinde.

## About

This repository contains multiple Jupyter notebooks covering essential Machine Learning concepts such as regression, classification, clustering, hyperparameter tuning, PCA, and ensemble learning. Each notebook demonstrates hands-on data preprocessing, model building, evaluation, and visualizations.

---

## Repository Structure

* **TitanicModels.ipynb**
  Complete ML workflow on the Titanic dataset – preprocessing, model training, evaluation.

* **Insurance.ipynb**
  Regression analysis on an insurance cost dataset.

* **HeartdiseaseFinal.ipynb**
  Classification model for heart disease prediction with preprocessing and model evaluation.

* **GridSearchCV.ipynb**
  Hyperparameter tuning using GridSearchCV for optimized model performance.

* **Clustring.ipynb**
  Clustering experiments (e.g., K-Means) with visualizations.

* **EnsembleLearning.ipynb**
  Ensemble methods like Random Forest, AdaBoost, Gradient Boosting.

* **PCADimensions.ipynb**
  Dimensionality reduction using PCA.

## Requirements

Install Python 3.8+ and recommended ML libraries.

### Suggested environment setup

```bash
python -m venv venv
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate        # Windows
```

### Install dependencies

```bash
pip install numpy pandas scikit-learn matplotlib seaborn jupyter notebook jupyterlab
```

You can also generate a `requirements.txt` if needed—ask me!

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/siddhesh1503/Machine-Learning.git
cd Machine-Learning
```

2. Start Jupyter:

```bash
jupyter lab
# or
jupyter notebook
```

3. Open any `.ipynb` file and execute cells in order.
